Parceiros para
projetos acadêmicos

Quer um parceiro para seu projeto? Este guia foi feito para te ajudar a encontrar uma parceria ou validar um contrato existente.

Antes de submeter

Como funciona o processo?

Verifique se você precisa de uma parceria para pesquisa de campo ou extensão e siga os passos abaixo antes de submeter seu projeto.

1

Identifique o perfil

Setor, porte e foco da organização desejada para a parceria.

2

Preencha o formulário

Descreva o perfil da parceria desejada no formulário ao lado.

3

Aguarde orientação

O comitê verificará se já existe uma parceria ativa adequada ao seu projeto.

Formulário de Identificação

Submissão do projeto

Como preencher o documento
de submissão?

O fluxo varia conforme a existência ou não de uma parceria ativa com a instituição desejada.

Já existe parceria ativa

Preencha o documento de submissão com o nome da instituição parceira. O comitê verificará o contrato vigente e liberará o acesso para o projeto.

Ainda não há contrato

Você será orientado a acessar o processo de nova parceria para formalizar o contrato antes de submeter o projeto.
